# Tombstones

Branches deleted from this repository, with what each was and how to bring it back: one JSON object a line in `branches.jsonl` (`branch`, `sha`, `last_commit`, `deleted`, `class`, `why`, `restore`). A branch that was the head of a pull request keeps its commits at `refs/pull/N/head`. Nothing is deleted without a line here first (owner's rule of 2026-10-16).
